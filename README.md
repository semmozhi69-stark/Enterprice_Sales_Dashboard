# Enterprise Sales Dashboard

## Project Overview

This project is an Excel-based sales dashboard created to analyze enterprise sales data. The dashboard provides important business insights such as total sales, total orders, average sales, quantity sold, category-wise sales, city-wise sales, payment methods, and order status.

## Tools Used

- Microsoft Excel
- Excel Formulas
- Lookup Functions
- Data Analysis

## Features

- Total Sales Analysis
- Total Orders Count
- Average Sales Calculation
- Total Quantity Sold
- Category-wise Sales Report
- City-wise Sales Report
- Payment Method Analysis
- Order Status Analysis

## Excel Formulas Used

- SUM()
- AVERAGE()
- COUNT()
- COUNTIF()
- SUMIF()
- INDEX()
- RANDBETWEEN()

## Dashboard Metrics

- Total Sales: 7,850,300
- Total Orders: 500
- Average Sales: 15,700.6
- Total Quantity: 1,693

## Project Structure

- Sales Data Sheet
- Employees Sheet
- Products Sheet
- Customers Sheet
- Dashboard Sheet
- Lookup Sheet

## Purpose

The main purpose of this project is to improve Excel skills and understand business data analysis.
